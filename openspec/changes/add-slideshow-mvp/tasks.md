Jeder Task ist höchstens etwa einen halben Tag groß und nennt, woran man sieht,
dass er erledigt ist. Abhängigkeiten stehen als „nach …“ dabei. Das
Golden-Frame-Prinzip (Vorschau ↔ Export) ist ohne Export noch nicht möglich.
Die Übergangs-Tasks werden deshalb über die Randwert-Golden-Frames in
TASK-WEB-011 abgesichert (design.md D8).
