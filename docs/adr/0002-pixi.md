# 0002 – Pixi for the whole repository

- **Status:** accepted (2026-10-02), change `add-slideshow-mvp`
- **Amends:** [ADR 0001](0001-architecture.md) (which still assumed uv and a
  Makefile)

## Context

The repository mixes Python (backend), TypeScript (web app), GLSL (shaders)
and FFmpeg as a native dependency. Until now this required uv, Node with pnpm,
a locally installed FFmpeg (version 4.3 on the development machine) and a
Makefile. The Product Owner wants **everything that can be managed by Pixi to
be managed by Pixi**.

## Decision

- `pixi.toml` + `pixi.lock` in the repository root, channel conda-forge,
  platforms linux-64, osx-arm64 and win-64.
- Pixi provides: Python 3.13, Node.js 24, pnpm 10, FFmpeg ≥ 7, Biome,
  glslang, Ruff, mypy, pytest, httpx2, jsonschema, Playwright, and all runtime
  dependencies of the backend. The backend is included as an editable PyPI
  package (`mmy-backend`, build backend hatchling).
- **pnpm** only manages npm packages that are not available on conda-forge
  (React, Vite, TypeScript, dnd-kit, …). The `packageManager` field in
  `package.json` must match the pnpm version provided by Pixi; CI checks this.
- **Pixi tasks** are the only command interface (`dev`, `check`, `test`,
  `gen-api`, …). There is no Makefile and no uv any more.
- Environments: `default` (with dev tools) and `prod` (backend image).
- `PYTHONNOUSERSITE=1` in the activation: packages from `~/.local` must not
  leak in. This actually happened locally — an old `websockets` crashed
  uvicorn.
- CI: `prefix-dev/setup-pixi` with `locked: true`, then `pixi run check`.

## Consequences

- (+) A fresh machine only needs Pixi. The FFmpeg version and the toolchain
  are locked and identical everywhere.
- (+) The Docker image builds the locked `prod` environment, without a second
  source of dependencies.
- (−) Two lockfiles (`pixi.lock`, `pnpm-lock.yaml`). This is unavoidable as
  long as npm packages are not on conda-forge.
- (−) conda-forge occasionally lags behind PyPI and npm.
- (−) Pixi needs a writable cache (`PIXI_CACHE_DIR`, see the
  [README](../../README.md#quick-start)).
